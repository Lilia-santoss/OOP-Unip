# Sistema de E-commerce

Projeto desenvolvido em C# durante a disciplina de Programação Orientada a Objetos, no curso de Análise e Desenvolvimento de Sistemas da Universidade Paulista (UNIP).

## Sobre o Projeto

Este projeto apresenta a implementação de um sistema de comércio eletrônico, desenvolvido com o objetivo de aplicar conceitos fundamentais da Programação Orientada a Objetos.

O sistema permite trabalhar com diferentes tipos de produtos e serviços, além de demonstrar a utilização de interfaces e diferentes formas de pagamento.

## Funcionalidades

- Cadastro de produtos físicos;
- Cadastro de produtos digitais;
- Cadastro de serviços;
- Gerenciamento de carrinho de compras;
- Cálculo do valor total da compra;
- Processamento de pagamentos.

## Tecnologias Utilizadas

- C#
- .NET
- Programação Orientada a Objetos
- Visual Studio / Visual Studio Code

## Conceitos de POO Aplicados

- Encapsulamento;
- Herança;
- Polimorfismo;
- Abstração;
- Interfaces;
- Injeção de Dependência.

## Estrutura do Projeto

O projeto é composto pelos seguintes arquivos principais:

| Arquivo | Descrição |
|--------|-----------|
| Produto.cs | Classe base para os produtos |
| ProdutoFisico.cs | Representação de produtos físicos |
| ProdutoDigital.cs | Representação de produtos digitais |
| Serviço.cs | Representação de serviços |
| CarrinhoCompras.cs | Gerenciamento dos produtos adicionados ao carrinho |
| Program.cs | Classe principal para execução do sistema |
| InterfacesPagamentoImplementações.cs | Interfaces e implementações relacionadas aos pagamentos |

## Objetivo Acadêmico

O projeto foi desenvolvido como atividade prática da disciplina de Programação Orientada a Objetos, com foco na aplicação dos princípios de desenvolvimento de software orientado a objetos.
