# Programação Orientada a Objetos – UNIP

Repositório desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas na Universidade Paulista (UNIP).

Este projeto reúne exercícios e atividades práticas relacionadas à Programação Orientada a Objetos, além de documentação técnica de um sistema de E-commerce.

## Conteúdos abordados

- Classes e objetos;
- Encapsulamento;
- Herança;
- Polimorfismo;
- Interfaces;
- Classes abstratas;
- Programação orientada a objetos;
- Desenvolvimento de sistemas.

## Projetos e atividades

### Exercícios de Programação Orientada a Objetos

Atividades práticas desenvolvidas durante a disciplina, envolvendo conceitos fundamentais da programação orientada a objetos.

### Sistema de E-commerce

Projeto acadêmico que simula um sistema de comércio eletrônico, envolvendo:

- Catálogo de produtos;
- Carrinho de compras;
- Processamento de pagamentos;
- Sistema de notificações;
- Arquitetura modular.

O projeto utiliza conceitos como herança, polimorfismo, interfaces, encapsulamento e baixo acoplamento.

## Tecnologias e conceitos

- C#
- Programação Orientada a Objetos
- Engenharia de Software
- Desenvolvimento de Sistemas
